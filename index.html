مراسلة الأقسام

مركز الإشعارات

تفعيل المزامنة — الملف يعمل محليًا

لأنك تفتح البرنامج كملف على جهازك، لا يسمح Firebase بتسجيل الدخول، فترفض القواعد الكتابة. اختر أحد الحلّين:
الحل السريع — فتح القواعد (للاستخدام الداخلي)

انسخ القاعدة التالية والصقها في: Firestore Database ← Rules ← Publish

فتح صفحة القواعد

تنبيه: هذه القاعدة تفتح البيانات لمن يعرف معرّف المشروع — استخدمها داخليًا فقط.

الحل الأفضل — رفع الملف على استضافة

سمِّ الملف index.html ثم:
npm i -g firebase-tools → firebase login → firebase init hosting → firebase deploy
وبعدها تعمل المزامنة بالقواعد الآمنة (request.auth != null) دون فتحها.
